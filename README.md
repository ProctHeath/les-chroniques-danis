# Les Chroniques d'Anis — V2

React + Vite immersive editorial portfolio.

## Install

```bash
npm install
npm run dev
```

## Stack

- React + Vite
- Framer Motion
- Lenis
- CSS

## Structure

- `src/components/` — reusable UI components
- `src/sections/` — page sections
- `src/hooks/` — animation / scroll hooks
- `src/data/chronicles.js` — texts and image data
- `public/images/` — project photography
